# Hi, I'm Giuseppe Cuiuri 👋

I build software and data projects, most of them started as coursework at the University of Calabria and then taken further: tested, documented and reproducible.

I hold an MSc in Computer Engineering (AI & Machine Learning) and I am looking for my first role in AI and machine learning, in Italy or remote.

## Selected projects

| Project | What it is |
| --- | --- |
| [**radon-anomaly-detection**](https://github.com/GiuseppeCuiuri/radon-anomaly-detection) | RADON, a robust autoencoder for unsupervised anomaly detection on MNIST and NSL-KDD. Research code refactored into a tested Python package, checked with differential tests against the original, with feature attribution for flagged anomalies. |
| [**QuestMaster**](https://github.com/GiuseppeCuiuri/QuestMaster) | Turns a lore document into a playable fantasy quest: a local LLM builds the world, a PDDL planner validates it, and the pipeline writes the story plus a React game. With [Davide Cinelli](https://github.com/davidecinelli26). |
| [**echo-search**](https://github.com/GiuseppeCuiuri/echo-search) | Multi-perspective search engine for divisive topics, with an echo-chamber measure, stance detection and fact-checking. With Davide Cinelli. |
| [**multilayer-influence-maximization**](https://github.com/GiuseppeCuiuri/multilayer-influence-maximization) | Influence maximization with a diversity constraint on multilayer social networks: Leiden communities, GraphSAGE diffusion probabilities, TIM/DTIM seeds. With Davide Cinelli. |
| [**us-flight-delays**](https://github.com/GiuseppeCuiuri/us-flight-delays) | 13.4 million US flights analysed with Apache Spark (Scala) and explored in an Angular dashboard with an in-browser delay-risk model. With Davide Cinelli. |
| [**Snakes-and-Ladders**](https://github.com/GiuseppeCuiuri/Snakes-and-Ladders) | A Snakes and Ladders simulator in Java 21 where every design pattern has a written reason. Redesigned from exam coursework with tests first, ArchUnit-enforced layering, a Swing window, a CLI and seeded replays. |

More: [Quantum-Kernel-SVM](https://github.com/GiuseppeCuiuri/Quantum-Kernel-SVM) (classical vs quantum-kernel SVMs, leak-free evaluation, with Davide Cinelli) · [CO2-emissions-regression](https://github.com/GiuseppeCuiuri/CO2-emissions-regression) (statistical modelling in R, group project) · [cartly](https://github.com/GiuseppeCuiuri/cartly) (Android shopping-list app, with Davide Cinelli) · [ShareSub-Backend](https://github.com/GiuseppeCuiuri/ShareSub-Backend) (Spring Boot REST API)
